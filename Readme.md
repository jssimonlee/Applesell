# AppleSell · 사과 주문서 정리

네이버폼 응답 엑셀을 배송 준비에 쓰기 좋은 주문서로 정리하는 정적 웹앱입니다. 파일 처리는 브라우저 안에서 이루어집니다.

## 사용 방법

1. `.xlsx` 또는 `.xls` 주문 파일을 선택하거나 끌어다 놓습니다.
2. 자동 정리된 상품명, 수량, 연락처와 주문 내역을 확인합니다.
3. **미리보기에서 시작할 주문 행을 클릭**합니다. 원본 주문서번호가 해당 번호 이상인 주문만 다운로드 대상입니다. 이전 주문은 진한 회색, 저장할 주문은 흰색으로 표시합니다. 키보드로는 행에 이동한 뒤 Enter 또는 Space로 선택합니다.
4. **수정본 다운로드**를 누릅니다. 선택된 주문의 순번은 **1번부터** 새로 매깁니다.

예를 들어 원본 주문번호가 2, 10, 15이고 시작 번호가 10이면, 원본 10번과 15번 주문만 순번 1, 2로 저장합니다. 원본 파일의 행 순서는 유지합니다.

## 출력 형식

미리보기와 엑셀 모두 아래 7개 열을 사용합니다.

`순번 / 사과상품선택 / 사과 수량선택 / 주문자이름 / 연락처 / 배송지주소 / 입금자/총입금액`

미리보기의 `1(원본7)` 표시는 새 순번과 원본 번호를 함께 보여줍니다. 엑셀에는 새 순번 `1`만 저장합니다. `#`, 동의 항목, 빈 열도 출력하지 않습니다. 연락처는 앞자리 0이 유지되도록 문자열로 저장합니다.

출력 파일명: `<원본파일명>_수정본_<시작번호>번부터.xlsx`

## 입력 처리

- 상품과 주문자이름 열이 있는 시트를 자동 선택합니다.
- 상품의 괄호 설명, 수량의 선택지 번호를 정리하고 연락처의 누락된 앞자리 0을 복원합니다.
- 내용이 없는 주문 행은 제외합니다.
- 주문번호가 없거나 비어 있으면 유효 주문의 행 순서로 번호를 부여합니다. 원본 주문번호는 1 이상의 정수여야 합니다.
- 다운로드 대상이 없으면 다운로드를 비활성화합니다.

## 로컬 실행

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 실행에는 Node.js 설치가 필요하지 않습니다. SheetJS는 기존과 같이 CDN에서 불러오므로 처음 페이지를 열 때 인터넷 연결이 필요합니다.

## 개발 및 검증

Node.js 20.19 이상에서:

```sh
npm ci
npm test
```

테스트는 주문번호 필터, 경계값, 빈 행 제외, 실제 XLSX 저장·재읽기, 연락처 문자열 유지, 미리보기와 다운로드의 데이터 일치, 입력 오류 및 파일 재선택을 검증합니다. 테스트에는 가상 주문만 사용합니다.

## GitHub Pages

기존 GitHub Actions 설정을 유지합니다. `main`에 푸시하면 Pages 배포 워크플로가 실행됩니다. 저장소 Settings → Pages의 Source는 **GitHub Actions**로 설정합니다.
